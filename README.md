# Customer Churn Analysis Using Power BI

**Platform:** DataCamp  
**Tools:** Microsoft Power BI, DAX  
**Project Type:** Data Analytics Portfolio Project  
**Year:** 2026

## Project Overview

Completed a customer churn analysis project on DataCamp using Microsoft Power BI and DAX to explore customer retention patterns.

The project focused on analysing customer churn through interactive visualisations, calculated columns and customer contract groupings.

## Project Objectives

- Explore customer churn and retention patterns.
- Investigate customer segments and contract groupings.
- Apply DAX calculations to support churn analysis.
- Present analytical findings through Power BI visualisations.

## Technical Skills Demonstrated

- Microsoft Power BI
- DAX functions: DIVIDE, COUNTROWS and SWITCH
- Calculated columns
- Customer segmentation
- Interactive dashboard development
- Data visualisation and analysis

## Project Work

- Developed an interactive Power BI dashboard as part of DataCamp coursework.
- Used DAX calculations to support customer churn analysis.
- Created calculated columns and contract groupings.
- Applied filters and visualisations to investigate customer retention patterns.
